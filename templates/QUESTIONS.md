# Questions message — template (away-mode, phone-friendly)

Use at every gate that needs the owner. One message, ≤ 6 questions, ★ = recommended = what `go` applies. Rules: `system/questions.md` §B.

```
<Tool> — <what I read / did, one line>. Need <N> answers (reply `go` for all ★, or e.g. `1b 3 skip 4`):

1. <Stem tied to a finding>
   ★a) <recommended> — <one-clause reason>
    b) <option>
    c) <option>
2. …

Found, no question: <facts I decided, so you can veto — e.g. pricing label Free (pricing page, <date>)>
Blocked until you answer: <only if something cannot be defaulted: license / price / logo / bot check>
Next after your reply: <what happens, e.g. "I open the resourceslist PR, then start the storyboard">
```

Short-form for a single yes/no gate:

```
<Gate name>: <link>. Reply `approved`, `approved except <x>`, or `changes: <scene/field> — <variable> → <absolute target>; leave <y> alone`.
```
